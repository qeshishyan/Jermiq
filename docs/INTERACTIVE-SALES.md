# Ինտերակտիվ պահեստամասերի ընտրություն և հավաքածուներ

Այս փոփոխությունը ավելացնում է երկու վաճառքային հնարավորություն՝ պահեստամասի ընտրության օգնական և համատեղելի հավաքածուի ընտրություն։ Վարպետների առանձին հաշիվների կամ գնային ծրագրերի փոփոխություններ չեն ներառվում։

## «Գտնենք ճիշտ մասը»

Գլխավորի հիմնական կոճակից և մենյուից բացվում է `/find-part` էջը։ Հաճախորդը կարող է սկսել՝

- `mode=code`՝ արտիկուլով, փոխարինման կոդով կամ անվանումով։ Կոդի բացատները և բաժանարարները չեն խանգարում որոնմանը։
- `mode=model`՝ սարքի տեսակից, բրենդից և հաստատված մոդելից։ Արդյունքները հիմնվում են ադմինում պահպանված համատեղելիության կապերի վրա։
- `mode=photo`՝ սարքի ընդհանուր տեսքի և տեխնիկական պիտակի լուսանկարներով հարցում ուղարկելով։ Լուսանկարները փոխանցվում են գործող հայտերի համակարգին՝ մասնագետի ստուգման համար։

Եթե մոդելների տվյալները դեռ լրացված չեն կամ արդյունք չկա, այցելուն կարող է շարունակել լուսանկարով։ Օգնականը չի ներկայացնում լուսանկարների ավտոմատ ճանաչման կամ համատեղելիության չհաստատված արդյունք։

Արդյունքի ընտրությունը հասանելի է նաև սովորական սերվերային GET ձևերով։ JavaScript-ը ավելացնում է քայլերի, արդյունքների ու հղման վիճակի ինտերակտիվ թարմացում։

## Համատեղելի հավաքածուի կառավարում

Բացեք `/admin?section=products`, ընտրեք հիմնական ապրանքը և «Համատեղելի հավաքածուի մասեր» դաշտում ընտրեք դրա հետ աշխատող հաստատված մասերը։ Պահպանելուց հետո դրանց ընտրության բլոկը հայտնվում է հիմնական ապրանքի էջում։

Հիմնական ապրանքը միշտ ներառված է։ Հաճախորդը կարող է միացնել/անջատել լրացնող մասերը և փոխել հավաքածուների քանակը։ Մեկ հավաքածուում յուրաքանչյուր ընտրված ապրանքից ներառվում է մեկ հատ։ Ավելի բարդ տարբեր քանակներով հավաքածուների կանոններ չեն ներմուծվում։

Ընտրված մասերի գների գումարը թարմացվում է անմիջապես։ Չլրացված գին ունեցող մասերի դեպքում ցուցադրվում է հայտնի գների գումարը, իսկ կողմնորոշիչ արժեքների դեպքում՝ համապատասխան նշումը։ Հավաքածուի կապը չի ստեղծում զեղչ կամ նոր գին։ Առաքման արժեքը ներառված չէ։

Զամբյուղ ավելացնելիս վերաստուգվում են հրապարակումն ու քանակը՝ ներառյալ զամբյուղում արդեն եղած ապրանքները։ Մի մասի խնդիր լինելու դեպքում ամբողջ ավելացումը մերժվում է, իսկ նախորդ զամբյուղը պահպանվում է։ Պատվերի ուղարկման պահին սերվերը դարձյալ ստուգում է արժեքներն ու առկայությունը։

Եթե հավաքածուի հաստատված մասեր ընտրված չեն, այդ ապրանքի էջում հավաքածուի ընտրիչ չի ցուցադրվում։ Սկզբնական տվյալներին համատեղելիության կամ հավաքածուների հորինված կապեր չեն ավելացվում։

## Տեսք, շարժումներ և տեքստեր

Գլխավոր էջի երեք ճանապարհները, ապրանքի ընտրության վիճակները և զամբյուղի արձագանքը օգտագործում են կարճ շարժումներ։ Համակարգի «նվազեցնել շարժումները» նախընտրությունը հարգվում է։ Հիմնական բովանդակությունը հասանելի է նաև առանց անիմացիաների։

Նոր հայերեն տեքստերի ռուսերեն և անգլերեն տարբերակները ներառվում են գործող թարգմանությունների բառարանում և խմբագրվում են ադմինի «Լեզուներ և տեքստեր» բաժնից։ Գլխավորի նախկին կարգավորվող վերնագիրը, նկարագրությունը և նկարը պահպանվում են։

## Ստուգումներ

```bash
dotnet build Jermiq.sln -c Release
python3 tests/interactive_sales_test.py --frontend
python3 tests/smoke_test.py --frontend
python3 tests/store_catalog_test.py --frontend
```

Թեստային հավաքածուն օգտագործում է առանձին ժամանակավոր բազա, փորձնական ապրանքներ և մոդելներ։ Գործող հաճախորդների կամ ապրանքային տվյալները չեն օգտագործվում որպես փոփոխվող թեստային նյութ։
