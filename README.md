# Ջերմիք — ամբողջական ASP.NET Core նախագիծ

Այս նախագիծը `https://jermiq.keshishyan1997.chatgpt.site/` կայքի ինքնուրույն գործարկվող .NET տարբերակն է։ Ներառված են backend-ը, frontend-ը, լոգոն, սկզբնական նկարները, հայերեն բովանդակությունը, տվյալների բազայի migrations-ը, SEO-ն և կառավարման բաժինը։

**Տեխնոլոգիաներ՝ ASP.NET Core 10 / .NET 10 LTS, C# 14, Razor Pages, EF Core 10, SQLite, ASP.NET Core Identity, HTML/CSS/JavaScript։** Frontend-ի համար Node.js կամ npm անհրաժեշտ չէ։ Microsoft-ի պաշտոնական տարբերակների ցանկը՝ https://dotnet.microsoft.com/download/dotnet ։ Ստեղծվել է 2026-10-09-ին՝ SDK 10.0.401 / runtime և NuGet փաթեթներ 10.0.12-ով։

## Արագ գործարկում Windows-ում

Տեղադրեք .NET 10 SDK-ն, բացեք նախագծի պանակը և գործարկեք՝

```powershell
dotnet restore Jermiq.sln
dotnet build Jermiq.sln
dotnet run --project src/Jermiq.Web
```

Կայքը բացվում է **http://localhost:5080** հասցեով։ Առաջին գործարկման ժամանակ բազան, աղյուսակները և սկզբնական տեսականին ստեղծվում են ավտոմատ։ Կարող եք բացել նաև `Jermiq.sln`-ը .NET 10 աջակցող Visual Studio-ում և գործարկել `Jermiq.Web` նախագիծը։

Կառավարչի ստեղծում՝ կայքի ընթացիկ գործընթացը փակելուց հետո.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-admin.ps1
dotnet run --project src/Jermiq.Web
```

Սցենարը հարցնում է էլ․ փոստը և գաղտնաբառը։ Գաղտնաբառը պետք է ունենա առնվազն 12 նիշ, մեծատառ, փոքրատառ, թիվ և հատուկ նշան։ Մուտք գործեք **http://localhost:5080/admin/login**։ Լռելյայն գաղտնաբառ չկա։ Պահպանվում է Identity-ի hash-ը, իսկ բաց գաղտնաբառը չի գրվում նախագծի ֆայլերում։

## Տվյալներն ու SEO-ի միացումը

`src/Jermiq.Web/App_Data` պանակում պահվում են SQLite բազան, ֆայլերը և մուտքի բանալիները։ Այս պանակը ստեղծվում է գործարկման ժամանակ և չի ներառվում ZIP-ում։ Պահպանեք այն վերատեղադրման ժամանակ և պահուստավորեք ամբողջությամբ։ Մեկ սերվերի փոքր բիզնես կայքի համար SQLite-ն ապահովում է ինքնուրույն գործարկում։ Բազմասերվեր տեղադրման համար անհրաժեշտ է ընդհանուր DB և ֆայլային պահոց։

`SeedData`-ում ներառված են սկզբնական 10 ապրանքը և օգտատիրոջ Excel/ZIP-ից ներմուծված 35 նախնական պահեստամասերը՝ 5 ապրանքանիշով։ Նոր բազան ունի 45 ապրանք։ Գործող բազայում նոր 35 գրառումները ավելացվում են մեկ անգամ՝ պահպանելով եղած տվյալներն ու հետագա խմբագրումները։ Նկարները նկարազարդումներ են, կոդերն ու համատեղելիությունը՝ չհաստատված, գները՝ դատարկ։ Մանրամասները՝ [ներմուծված կատալոգ](docs/UPLOADED-CATALOG.md)։ Հեռախոսը, հասցեն և իրական ապրանքային տվյալները լրացվում են `/admin`-ից։ Հին կայքի հաճախորդների հայտերն ու կառավարման հաշիվը չեն ներառվում կոդի փաթեթում․ նոր տեղադրումն ունի իր բազան։ Հրապարակված սկզբնական կայքի կոդը կամ տվյալները այս աշխատանքի ընթացքում չեն փոփոխվել։

Հանրային դոմեյնի վրա տեղադրելիս կարգավորեք՝

```text
ASPNETCORE_ENVIRONMENT=Production
Seo__BaseUrl=https://YOUR_DOMAIN
Seo__IndexingEnabled=true
Security__RequireHttps=true
Persistence__DataDirectory=/persistent/path/jermiq
```

Զարգացման և նախնական տեղադրումների համար ինդեքսավորումն անջատված է։ Demo ապրանքները միշտ `noindex` են և չեն հայտնվում sitemap-ում։ Իրական ապրանքների դեպքում կառավարումից անջատեք «Ցուցադրական օրինակ»-ը։ Դոմեյնը լրացնելուց հետո sitemap-ը կազմվում է ավտոմատ։

## Ստուգումներ

```bash
dotnet build Jermiq.sln -c Release
python3 tests/smoke_test.py
```

Python սցենարը իր ժամանակավոր բազայով ստեղծում է թեստային կառավարիչ, գործարկում է կայքը, ստուգում իրական HTTP հարցումներով և վերջում հեռացնում միայն իր ժամանակավոր տվյալները։ Այն ստուգում է բոլոր էջերը, SEO-ն, հայտերի տեսակները, լուսանկարները, նույն հայտի կրկնությունը, մուտքի ու CSRF-ի պաշտպանությունը, ապրանքների և պայմանների փոփոխությունները։ Պահանջվում է Python 3 և .NET 10 SDK։ Frontend-ի բրաուզերային պատկերային ստուգումը այս միջավայրում չի կատարվել․ օգտագործված են սկզբնական CSS-ն ու նկարները։

Կամընտիր frontend գործառութային ստուգումներ՝ Node.js 24-ով և jsdom-ով.

```bash
npm install --prefix tests
python3 tests/smoke_test.py --frontend
```

Սա DOM միջավայրում ստուգում է իրական API-ին միացած պատվերի ցանկը, համեմատությունը, ընտրության օգնականը, հայտի ձևերը, մուտքի տակ գտնվող կառավարման UI-ն և HTML սխալ պատասխանների մշակումը։ Node.js-ն անհրաժեշտ է միայն այս կամընտիր թեստերի համար։ Կատարված ստուգումների ամփոփումը՝ [docs/VALIDATION.md](docs/VALIDATION.md)։

## Հաջորդ կոդային փոփոխությունները

Հայերեն ստատիկ բովանդակությունը՝ `Pages/Shared`, օգտակար նյութերն ու ծառայությունները՝ `SeedData/articles.json` և `SeedData/services.json`, CSS-ը՝ `wwwroot/css`, ինտերակտիվ գործառույթները՝ `wwwroot/js`, API-ն՝ `Endpoints/ApiEndpoints.cs`։ DB փոփոխությունների համար ստեղծեք նոր EF migration և կիրառեք այն տեղադրման ընթացքում։ Գործող seed ապրանքները վերագործարկումով չեն վերագրվում։

## Եռալեզու CMS և օֆիսի կառավարում

Կայքն ու ադմինը աջակցում են հայերեն, անգլերեն և ռուսերեն։ `/admin`-ը ներառում է օֆիսի հայտերի աշխատանքային սեղան, սեփական տեսակի հայտերի ձեռքով մուտքագրում, պատասխանատուներ, ժամկետներ, ներքին նշումներ, պատմություն, CSV, հոդվածներ/ծառայություններ, տեքստերի և թիմի կառավարում։ Օգտագործման և ստուգումների ուղեցույցը՝ [docs/CMS.md](docs/CMS.md)։

## Իրական մոդելների հավելում

Ավելացվում են 6 Ariston ջրատաքացուցիչ և 4 Thermex պահեստամաս՝ արտադրողների նկարների հղումներով և փոփոխելի կողմնորոշիչ գներով։ Ներմուծումն աշխատում է առաջին վերագործարկման ժամանակ և չի փոխարինում նախկին ապրանքները։ Գները խմբագրեք `/admin` բաժնում, իսկ վերջնական գին սահմանելիս անջատեք «Կողմնորոշիչ գին» նշումը։ Հետագա վերագործարկումները չեն վերագրում գներն ու չեն վերադարձնում հեռացված ապրանքները։ Աղբյուրներն ու նկարների սահմանափակումները՝ [docs/real-catalog-sources.md](docs/real-catalog-sources.md)։
